# P21 — Data dictionary + known quirks

## The orders file — `data/raw/orders_SAMPLE.csv`

SAMPLE e-commerce orders for the fictional Pakistani online store
**PakBazaar**, Thu 2026-01-01 → Tue 2026-06-30 (6 months, 181
days). 1,200 orders, 217 returns (18.08%), gross revenue
PKR 4,203,195, refunded PKR 564,528, return shipping PKR 51,500,
money lost PKR 616,028. Generated by `src/generate_data.py`
(seed 20261117) with deliberately different behaviour per category
(Fashion returns most at 30.17%, Beauty least at 6.92%), per
channel (Daraz returns most at 21.30%, Facebook least at 14.67%)
and per month (March carries a sale spike, so returns spike there
at 23.73%) — so the report has a real category story, a real
channel story and a real monthly story to surface.

| Column | Type | Meaning |
|---|---|---|
| order_id | text | `ORD-0001` … `ORD-1200`; the order key |
| order_date | text | `yyyy-mm-dd`; the day the order was placed |
| month | text | `yyyy-mm`; the report's month key |
| category | text | One of 5: Fashion, Electronics, Home & Kitchen, Beauty, Sports |
| channel | text | One of 4: Website, Daraz, Facebook, WhatsApp |
| product_name | text | One of 20 products (4 per category) |
| product_sku | text | `FAS-001` … `SPO-004`; the product key |
| quantity | integer | 1 or 2; 15% of orders are 2 units |
| order_value_pkr | integer | Product price × quantity (PKR) |
| return_status | text | Kept or Returned |
| return_reason | text | Empty for kept orders; one of 6 reasons for returns: Wrong size, Defective/damaged, Wrong item sent, Late delivery, Quality not as expected, Changed mind |
| resolution | text | Empty for kept orders; Refunded or Replaced for returns |
| refund_amount_pkr | integer | Full order value when refunded, 0 when replaced or kept |
| return_shipping_cost_pkr | integer | Fixed per-channel courier cost on every return (Website 250, Daraz 200, Facebook 300, WhatsApp 250), 0 for kept orders |

## The processed files — `data/processed/`

- `orders_enriched.csv` — all 1,200 orders with the derived
  columns attached: is_returned (0/1) and money_lost_pkr
  (refund + return shipping, 0 for kept orders) — produced by
  `src/analyze.py`.
- `category_summary.csv` — one row per category (5 rows): orders,
  returns, return rate, gross revenue, refunded revenue, return
  shipping cost, money lost, net revenue, revenue kept, average
  order value.
- `channel_summary.csv` — one row per channel (4 rows), same
  columns as the category summary.
- `reason_summary.csv` — one row per return reason (6 rows):
  returns, share of returns, refunded revenue, return shipping
  cost, money lost, share of money lost — ranked by returns.
- `product_summary.csv` — one row per product (20 rows), same
  columns as the category summary plus the top return reason for
  that product.
- `monthly_summary.csv` — one row per month (6 rows), same
  columns as the category summary plus the month-on-month change
  in return rate (blank for January).

## The analysis method — `src/analyze.py`

Return rate = 100 × returned orders / total orders, in every group
shown. Money lost = refunded revenue + return shipping cost, so
gross revenue − refunded revenue = net revenue and gross revenue −
money lost = revenue kept after all return costs. Every group total
(category, channel, reason, product, month) sums to the same
headline numbers — `src/checks.py` verifies all of it. The
fix-first actions rank where the money is lost: the top reason by
count and by money (Wrong size, PKR 157,156), the worst channel
by rate (Daraz, 21.30%), the store-caused returns
(Defective/damaged + Wrong item sent, PKR 88,927 together), and
the sale-spike month (March, 23.73%).

## Known quirks

- **March is the worst month by rate, April by money.** March has
  the highest return rate (23.73%, 56 returns) — the sale spike —
  but April lost the most money (PKR 156,761), when pricier orders
  came back. Rate and money point at different months; the report
  shows both.
- **Website lost the most money, Daraz has the worst rate.**
  Website lost PKR 272,427 in absolute terms because it carries
  the most orders (508) — its rate is the second lowest (16.93%).
  The channel problem is Daraz (21.30%), not Website.
- **The worst product by rate is not the worst by money.**
  Women's Lawn 3pc Suit has the highest return rate (33.33%,
  32 of 96 orders), but Running Sneakers lost the most money
  (PKR 105,378, 27 returns) — a lower rate on a pricier product
  still costs more.
- **Bedsheet Set barely returns at all.** 1 return in 55 orders
  (1.82%) — the lowest-rate product. On a real file that small a
  count would be checked before celebrating it.
- **No .db is shipped.** This is an Excel-led project: the raw
  and processed files are plain CSVs, and the workbook is the
  working report. Nothing needs a database.
